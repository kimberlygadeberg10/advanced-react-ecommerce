# Advanced React E-Commerce App

A full-featured e-commerce web application built with React, TypeScript, Firebase, and modern development tools. The app allows users to create accounts, manage profiles, browse products, shop through a cart, place orders, and view order history.

## Live Application

[View the live app here](https://advanced-react-ecommerce-pink.vercel.app/)

## Key Features

* User registration, login, logout, profile updates, and account deletion
* Product viewing, adding, editing, and deleting
* Shopping cart with quantity and price tracking
* Cart storage using `sessionStorage`
* Order placement and order history
* Firebase Authentication and Firestore data storage
* Fallback images for missing or broken product images
* Automated testing and CI/CD deployment

## Technologies

* React + TypeScript
* Vite
* React Router
* Redux Toolkit
* React Query
* Firebase Authentication & Firestore
* Jest & React Testing Library
* GitHub Actions
* Vercel

## Project Highlights

Firebase is used to manage user authentication and store product, profile, and order data. Redux Toolkit handles shopping cart state, while React Query manages data fetching and updates.

The project also includes automated testing with Jest and React Testing Library. GitHub Actions runs tests and builds the application before deployment to Vercel.
